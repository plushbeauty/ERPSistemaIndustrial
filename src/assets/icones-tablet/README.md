# Ícones da Mesa Tablet

Coloque nesta pasta exclusivamente os ícones oficiais da Mesa Tablet do ERP Industrial.

## Convenção recomendada

Use um arquivo por módulo, preferencialmente com o número e nome do módulo:

- 01-configuracoes.svg
- 02-vendas.svg
- 03-compras.svg
- 04-estoque.svg
- 05-expedicao.svg
- 06-fiscal.svg
- 07-rh.svg
- 08-engenharia.svg
- 09-materiais.svg
- 10-mrp.svg
- 11-pcp.svg
- 12-chao-de-fabrica.svg
- 13-qualidade.svg
- 14-sgq.svg

A Mesa Tablet lê automaticamente os arquivos de imagem desta pasta. Quando os novos ícones forem adicionados aqui, eles passam a ser usados pela central sem precisar criar um componente separado para cada ícone.
